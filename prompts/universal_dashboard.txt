UNIVERSAL VISUALIZATION RULES (apply to any domain)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ALWAYS include at least one KPI card showing the most important single metric
2. ALWAYS include a time-series chart if any date/timestamp column exists
3. ALWAYS include a breakdown chart (bar or pie) for the primary categorical dimension
4. For datasets with > 2 numeric columns: add a scatter or comparison chart
5. For datasets with funnels/stages: use a funnel chart
6. If no obvious metrics: use count aggregation on categorical columns
7. Prefer "sum" aggregation for money/volume, "avg" for rates/scores, "count" for events/records

POSITION STRATEGY (12-column grid):
- 2 KPI cards side by side: each w=3, h=2, x=0,3,6,9
- Main chart (bar/line): w=8, h=5
- Secondary chart (pie/donut): w=4, h=5
- Full-width chart: w=12, h=5
- Table: w=12, h=6

SMART FIELD MAPPING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When choosing x_field / y_field, follow this priority:
- y_field (metric): prefer numeric columns matching domain keywords above
- x_field (dimension): prefer string or date columns (dates for trends, strings for categories)
- If multiple numeric columns: use the one with highest variance / most meaningful name
- Map abbreviated names: amt → amount, qty → quantity, cnt/count → count, pct → percentage
- id columns (ending in _id, _code, _key) → skip these as axis fields, use as filters only
